<objective>
Complete the harder corpus with the **negative / unsupported (honest-refusal)** class and
lock in the regenerated scripted regression gate. Author ≥3 `expect_refusal: true` cases
whose NL asks something the ontology cannot honestly answer (an unanswerable / absent-term
question) or requires an unsupported SPARQL construct (transitive `+`/`*`, alternative `|`,
or negated path — the operators the deterministic transpiler rejects). Each negative's
`expected` field holds a short human-readable **rationale** (documentation only — the
`CorpusCase` gate does NOT parse it as gold, per Plan 01), and its `scripted:` canned
response is authored to trigger a genuine transpiler rejection so `outcome.aql == ""` and
the inverted judge scores it PASS deterministically. Retain the existing deliberate
near-miss so the scripted pass_rate stays **meaningfully < 1.0**. Then regenerate
`baseline.json`'s scripted config from the ACTUAL `run("scripted")` output and extend
`test_eval.py` with a scripted-pass_rate-< 1.0 headroom-invariant assertion.

Purpose: Negatives are the single most dangerous deployment mode (silently-wrong-but-
parseable) and the honest-refusal dimension the AI-SPEC scores by the inverted convention
(NL-EVAL-03 SC1). The retained near-miss keeps `baseline.json` a real gate (SC2). The
regenerated baseline is authored from the true run, never aspirational (Phase 6 discipline).
**Transpiler-untouched — W3C ≥ 96.4% preserved.**
Output: negative cases in `corpus.yml`, a regenerated scripted `baseline.json`, and a
tightened `test_eval.py`.

IMPORTANT nuance to honor (do NOT silently work around): this repo's `SchemaResolver` has
an **unmapped-IRI fallback** (unknown IRIs resolve to a default collection with a schema
WARNING, not an error). So a merely-unknown-class query can STILL transpile to non-empty
AQL. Therefore a scripted negative must be made to refuse via a GENUINE transpiler
rejection (unsupported path operator or a parse error), NOT merely an unknown class name —
otherwise `outcome.aql` is non-empty and the refusal case FAILS under scripted. The NL may
still describe an absent-term question; it is the canned scripted response that must be
transpiler-rejected.
</objective>
