<objective>
Close NL-FEW-02: prove a measurable, noise-clearing NL→SPARQL pass-rate lift from
dense few-shot over the Phase 06.2 live-model baseline, via the Phase 6 harness.

Four moving parts, all additive and gated:
1. **Critical blocker fix (RESEARCH Pitfall 2):** `OpenAICompatibleClient.generate()`
   unconditionally sends `temperature=0.1`, which gpt-5-family reasoning models reject
   with a 400 — every gpt-5/gpt-5-mini arm would hard-fail. Add a `_is_reasoning_model`
   predicate that omits `temperature` for those models. Add gpt-5-family pricing rows so
   cost accounting is not silently `$0.00` (Pitfall 4).
2. **Harness extension (RESEARCH Open Question 2 / Pitfall 5):** extend `configs.yml`
   with the 3-arm × 3-model matrix and an optional `few_shot: {mode, k}` block, and add a
   narrow additive read in `runner.py` that threads it into `NlPipeline` via the 07-03
   passthrough. `run(config_name) -> Report` stays byte-identical; `scripted` stays the CI
   default. The dense arm asserts `isinstance(index.retriever, DenseRetriever)` (D-06)
   before recording, and `BaselineConfig` gains the D-04 embedding-provenance fields.
3. **The gated sweep runbook (D-07/D-08/D-09):** a README section documenting the
   self-baselining 3-arm × capability-tier × N=3 sweep, the `dense_mean − zero_mean >
   max within-arm spread` bar, a live model-resolution check before running (Open
   Question 3), and the MANUAL human-reviewed fold-in — mirroring 06.2's discipline, run
   behind `RUN_EVAL=1` + `NL2SPARQL_API_KEY`, never in CI.
4. **SC4 non-regression guard:** the phase touches no transpiler code; the W3C harness is
   run at the phase gate to assert coverage stays ≥ 96.4%.

Purpose: NL-FEW-02 — the measured lift that justifies the whole phase. Depends on the
07-03 wiring (dense/BM25/zero arms are only selectable once the seam + pipeline
passthrough exist).
Output: the temperature fix + pricing rows, the extended configs/runner, the sweep
runbook, structural + unit tests (no-network), and a documented W3C non-regression check.
</objective>
