## Sampling Rate

- **After every task commit:** Run `pytest tests/nl2sparql/eval/test_gold_transpilable.py tests/nl2sparql/eval/test_generator.py -x` (fast no-network subset covering the new generator's own correctness)
- **After every plan wave:** Run `RUN_EVAL=1 pytest -m eval -q` (full harness, still no-network on the `scripted` default path)
- **Before `/gsd-verify-work`:** Full suite green **+** `pytest tests/w3c/test_coverage_gate.py -x` (W3C ≥ 96.4% non-regression)
- **Max feedback latency:** ~60 seconds
