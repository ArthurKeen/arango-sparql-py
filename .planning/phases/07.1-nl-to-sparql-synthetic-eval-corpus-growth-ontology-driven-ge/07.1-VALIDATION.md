## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `pytest` (repo-wide; the `eval` marker gates this harness specifically) |
| **Config file** | `pyproject.toml` (marker declarations) — no dedicated eval config file |
| **Quick run command** | `pytest tests/nl2sparql/eval/test_gold_transpilable.py tests/nl2sparql/eval/test_judge.py -x` (fast, no-network) |
| **Full suite command** | `RUN_EVAL=1 pytest -m eval -q` |
| **Estimated runtime** | ~30–60 seconds (scripted no-network path; live sweeps are out-of-band) |

---

## Sampling Rate

- **After every task commit:** `pytest tests/nl2sparql/eval/test_gold_transpilable.py tests/nl2sparql/eval/test_judge.py -x` (fast, no-network; covers conversion correctness for whichever set was just touched)
- **After every plan wave:** `RUN_EVAL=1 pytest -m eval -q` (full harness, still no-network on every `scripted*` config)
- **Before `/gsd-verify-work`:** Full suite green **+** `pytest tests/w3c/test_coverage_gate.py -x` (W3C ≥ 96.4% non-regression)
- **Max feedback latency:** ~60 seconds
